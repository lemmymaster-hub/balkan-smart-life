# BSL EV charger fallback snapshot

`bsl_ev_chargers_bih.json` je read-only OpenStreetMap/Overpass snapshot javno
mapiranih EV punjača u Bosni i Hercegovini. Uključen je u APK da EV mapa ne
ostane prazna kada javni Overpass serveri privremeno ne odgovaraju.

- OSM stanje: `2026-08-21T18:00:10Z`
- Overpass area: `3602528142` (Bosna i Hercegovina)
- Broj sirovih OSM elemenata: `138`
- Licenca i atribucija: ODbL, © OpenStreetMap contributors

Mobilni klijent u pozadini pokušava dohvatiti noviji snapshot; ovaj fajl nije
zamjena za live osvježavanje niti dokaz da je pojedini punjač trenutno u radu.
